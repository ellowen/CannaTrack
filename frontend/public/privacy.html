Politica de Privacidad

Ultima actualizacion: Octubre 2026

Que datos recolectamos

  • Cuenta: tu direccion de email para autenticacion.
  • Cultivo: datos que vos ingresás: nombre de plantas, genetica, fechas, notas, fotos.
  • Dispositivo: token de notificaciones push (solo si das permiso).
  • Uso: eventos anónimos de uso (por ejemplo, que se abrió la página o que se creó una planta) con un identificador aleatorio de la pestaña. No llevan tu email ni tu cuenta, no usan cookies, y no se miden si tu navegador tiene activado “No rastrear”.

Como usamos los datos

  • Para mostrarte tu historial de cultivo y tareas del dia.
  • Para enviar recordatorios de riego/nutricion (si activas las notificaciones).
  • Para aplicar los limites del plan Free/Pro (por ejemplo, la cantidad de plantas activas).

No vendemos tus datos

CultiTrack no vende, alquila ni comparte datos personales con terceros con fines comerciales. Los unicos proveedores que reciben datos son los necesarios para el funcionamiento del servicio (Supabase para base de datos, autenticacion y almacenamiento de fotos, y el servicio de notificaciones push de tu navegador si activas las notificaciones).

Fotos de plantas

Las fotos que subis al diario se almacenan en servidores seguros (Supabase Storage). Solo vos podes verlas.

Seguridad

Todos los datos se transmiten con HTTPS. El acceso a la base de datos esta protegido por Row Level Security: ningún usuario puede ver datos de otro.

Tus derechos

Podes solicitar la eliminacion de tu cuenta y todos tus datos en cualquier momento escribiendo a cultitrack@gmail.com.
